The coding agent that doesn't stop when your account does

A terminal coding agent for GitHub Copilot's models, Claude and models on your own machine. It shows where your tokens go, and you can drive it from your phone.

curl -fsSL https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.sh | bash
irm https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.ps1 | iex

No account or token needed. The installer checks every file against the release's SHA256SUMS. Other ways to install, and what gets installed

One install, three parts

Start the proxy once. The agent, your phone and your other tools all talk to it.

The agent

A coding agent in your terminal

  • Asks before it writes a file or runs a command. deny rules are absolute.
  • Reads Claude Code's subagents, slash commands, skills, hooks and MCP servers from the repo, so an existing project needs no second setup.
  • Compile errors right after each edit, from the language servers you already have.
  • A live status bar: context used, tokens spent, the model and your remaining allowance. Paste or drop an image into the prompt.
Your first session →

The proxy

Your accounts and models in one place

  • Sign in to GitHub Copilot in the browser, or save an Anthropic API key. Keys go in your system keyring, not a config file.
  • Ollama, LM Studio, oMLX, Lemonade and Unsloth are detected and probed. Any OpenAI-compatible server works.
  • When an account runs out, requests move on to the next account or model, mid-task.
  • Speaks the OpenAI and Anthropic APIs, so Claude Code, OpenCode and other tools can use your models too.
  • A setup page at 127.0.0.1:11539 that only listens on this machine, with an optional password.
The proxy and its setup page →

Your phone

Approve and steer from your phone

  • Pair with a short code that works once, or scan a QR code. Set it up with Tailscale for a real HTTPS certificate.
  • See the exact diff before you approve a tool call. Start new sessions in folders you allowed.
  • Notifications when a session needs you, with no commands, paths or error text in them.
  • Share one session read-only: a link that lets one person watch it live, with no sending and no approvals, until the share ends.

Used from an iPhone on a home network. Other setups are not yet verified.

Don't take our word for it

Costs vary from task to task and run to run. Measure your own work, and read what we measured with its limits.

Check it yourself

  • /cost in a session: what the task used, and what was read from the cache.
  • The proxy's Cache card: the hit rate and AI units per request, for every tool that uses the proxy.
  • maple-harness bench: repeated, paired runs of your own tasks, with a spending cap.
How to check it yourself →
Measured

Against GitHub Copilot CLI, on the same model

In seven paired runs over four tasks, Maple Harness used fewer AI units than Copilot CLI in every pair: task by task, between 21% and 40% fewer, and about 27% fewer at the median.

When
27 September 2026, one day
Account
One GitHub Copilot business-seat account, used by both tools
Model
gpt-6-sol for both
Tasks
Four small coding tasks (Go tests, BDD specifications, a small web app): three run twice and one once per tool, seven paired runs in all
Counted by
GitHub's own AI-unit count for each tool's requests

Copilot CLI finished each task faster, by about 14% at the median. Both tools passed the tasks' automated checks on the same one run of seven, so this compares cost, not quality. One account, one model, one day: a real result, not a promise for your tasks.

Measured

A larger task, one run each

Both agents were given the same specification (an offline expense-tracker app with 20 named BDD scenarios), the same model (gpt-6-sol) and the same machine. Each side's figures come from its own accounting, and wall time is taken from outside the process. This is a single run: a later comparable run on another machine went the other way, so treat it as an example, not a rule, and measure your own with /cost and the proxy's Cache card.

The Copilot CLI's report gives the AI-unit total and the wall time but not the token breakdown, so only those two rows are directly comparable. Both runs produced every required document, a clean tree and passing checks.
