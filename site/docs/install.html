Install #

Maple Harness is two programs: maple-harness (the agent, also available as mpl) and maple-proxy (which holds your sign-ins and talks to the models, also mplp). On Apple silicon there is a third, a small helper for Apple's on-device model. The installer fetches all of them.

One line #

macOS and Linux:

curl -fsSL https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.sh | bash

Windows (PowerShell):

irm https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.ps1 | iex

No account or token is needed. The installer detects your system, downloads the release, checks every file against the release's SHA256SUMS, and refuses to install anything that does not match. To read it first, open it on GitHub.

By default it installs to /usr/local/bin. To choose another place, or a specific release:

curl -fsSL https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.sh | bash -s -- --install-location ~/.local/bin
MAPLEHARNESS_VERSION=v1.0.0 curl -fsSL https://raw.githubusercontent.com/kinncj/maple-harness-dist/main/install.sh | bash

Check it worked:

maple-harness version
maple-proxy version

Optional: contain the shell (bubblewrap) #

The agent can run the commands its shell tool executes inside a sandbox. On macOS that is built in. On Linux it needs bubblewrap, which is optional: without it the shell still works, uncontained.

SystemCommand
Arch, Manjarosudo pacman -S bubblewrap
Debian, Ubuntusudo apt install bubblewrap
Fedora, RHELsudo dnf install bubblewrap
openSUSEsudo zypper install bubblewrap
Alpinesudo apk add bubblewrap

Run /sandbox inside the agent, or maple-harness doctor, to see whether it works on your machine.

With the network allowed, contained commands still cannot connect to the proxy's setup page, so a command cannot change your settings or read your keys through it. They can reach everything else as before: the proxy's model addresses, your own local servers and the internet. On Linux this needs version 6.7 or later; on an older kernel commands run as before. /sandbox shows whether the setup page is blocked on your machine. The rule is by port, so a service on another computer that uses the setup page's port (11539 unless you changed server.webui) cannot be reached from a contained command either. Contained commands also cannot use Multipath TCP while the page is blocked: curl --mptcp fails as it would on a system with Multipath TCP switched off, and plain curl works.

Update #

maple-harness update --check     # is there a newer release?
maple-harness update             # install it
maple-proxy update               # the proxy updates itself the same way

Uninstall #

rm -f /usr/local/bin/maple-{harness,proxy,sidecar} /usr/local/bin/{mpl,mplp}
rm -rf ~/.config/maple-harness     # your config, sign-ins, notes and saved sessions

The second line deletes your configuration, stored sign-ins, memory notes and saved sessions. Skip it if you plan to reinstall.
