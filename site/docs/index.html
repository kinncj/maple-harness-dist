    Overview #

    On this page
    1. Start here
    2. Get started
    3. Guides
    4. Cost and usage
    5. Reference
    6. Help

    Maple Harness is a coding agent for GitHub Copilot's models, Claude and models on your own machine. It comes in three parts:

    • The agent, maple-harness: the program you work with in a terminal. It reads your project, edits files and runs commands, and asks before it changes anything.
    • The proxy, maple-proxy: holds your sign-ins and talks to the models, for the agent and for any other tool that speaks the OpenAI or Anthropic API. Its setup page is where you sign in and change settings.
    • The phone page: share a session and drive it from your phone's browser, or from another computer.

    On a Mac with Apple silicon there is also a small helper for Apple's on-device model, which the proxy starts when it is needed.

    Start here #

    1. Install the programs.
    2. Run Your first session.
    3. Sign in to GitHub Copilot or Claude, or Connect a model server such as Ollama or LM Studio.
    4. Choose a model, or let the agent choose for each message.

    Installing, signing in and connecting models.

    • Install: the one-line installer, platforms, updating and removing it.
    • Your first session: start the proxy and the agent, and the first commands to know.
    • Sign in: GitHub Copilot, an Anthropic API key, and more than one account.
    • Connect a model server: Ollama, LM Studio, oMLX, Lemonade, Unsloth or any OpenAI-compatible server.
    • Choose a model: switch models, let the agent choose, and set a default.

    Guides #

    How each part works, and how to use it with other tools.

    The agent

    • Subagents: hand small jobs to helper agents, or make your own.
    • Language servers: compile errors right after every edit.
    • Search by meaning: let the agent find things by what they mean, not only the words.
    • The shell sandbox: contain the commands the model runs, and what that breaks.

    The proxy

    • The proxy and its setup page: what it listens on, the setup page and the settings you may want.
    • Keep it running in the background: run the proxy and the phone gateway as a service.

    Your phone

    • Control it from your phone: pair a phone, approve tool calls, start sessions and share one read-only.

    Other tools

    • Use your models from other tools: point Claude Code, OpenCode or another tool at the proxy.
    • What the proxy adds for other tools: what those tools gain from it, and what stays in the agent.
    • Give other tools this project's knowledge: the MCP server.
    • Drive it from another program: a script, an editor plugin or CI.
    • Use it with herdr: see the agent's state in a herdr pane.
