    Overview #

    On this page

    2. Start here
    3. Get started

    6. Reference
    7. Help

    Maple Harness is a coding agent for GitHub Copilot's models, Claude and models on your own machine. It comes in three parts:

    • The agent, maple-harness: the program you work with in a terminal. It reads your project, edits files and runs commands, and asks before it changes anything.
    • The proxy, maple-proxy: holds your sign-ins and talks to the models, for the agent and for any other tool that speaks the OpenAI or Anthropic API. Its setup page is where you sign in and change settings.
    • The phone page: share a session and drive it from your phone's browser, or from another computer.

    On a Mac with Apple silicon there is also a small helper for Apple's on-device model, which the proxy starts when it is needed.

    In plain words #

    • The agent is where you work: type what you want done in a terminal, and it reads, edits and runs, asking first.
    • The proxy holds your accounts and models. Its setup page, at http://127.0.0.1:11539, is where you sign in and change settings, with nothing to edit by hand.
    • Your phone can follow a session and approve what the agent asks.
    • Curious what makes it different? What's inside Maple describes the capabilities in plain words.

    Start here #

    1. Install the programs.
    2. Run Your first session.
    3. Sign in to GitHub Copilot or Claude, or Connect a model server such as Ollama or LM Studio.
    4. Choose a model, or let the agent choose for each message.
